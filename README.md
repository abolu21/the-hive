# The Hive

The Hive is a web-based chatroom for people to talk about shared interests. You choose a username—no account is required—and join a room.

There are public rooms for topics such as AI, politics, football, music, and personal development. You can stay connected to multiple rooms and switch between them. In a room, you can see who’s there and who’s typing, reply to a specific message, and mention someone who’s currently in the room.

You can also create personal rooms for 1–100 people. They’re unlisted, so you join by entering the room’s exact name. Anyone who knows the name can join; it isn’t account-based access control. When the last person leaves, the room and its messages are deleted.

Messages in public rooms are saved so they’re available when you return. Messages are not end-to-end encrypted: the server and database can read them. The Hive also doesn’t currently have accounts or a moderation system, so share personal room names thoughtfully and be considerate in conversation.
